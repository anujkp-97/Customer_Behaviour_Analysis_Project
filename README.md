# Customer_Behaviour_Analysis_Project

This project analyzes customer purchasing behavior using Excel, Python, MySQL, SQL, and Power BI. The project includes data cleaning, SQL-based business insights, and interactive dashboard creation. Power BI dashboards were developed using Power Query and DAX to track KPIs, revenue trends, product performance, and seasonal sales patterns.

## Tools & Technologies Used:- 
- Python (Pandas, NumPy)
- MySQL
- SQL
- Power BI
- Power Query
- DAX
- Advanced Excel

## Key Features
- Performed data cleaning, missing value handling, duplicate removal, and category standardization.
- Exported cleaned datasets into MySQL for query-based analysis.
- Wrote SQL queries to analyze.
- Developed interactive Power BI reports and KPI dashboards for business insights and performance tracking.
- Used Power Query and DAX functions for data transformation, calculated measures, and dynamic reporting.
